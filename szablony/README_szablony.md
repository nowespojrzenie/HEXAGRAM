# STARTER Obsidiana — 3 kroki, resztę ignoruj
1. Obsidian → Ustawienia → **Core plugins** → włącz **Templates** (Szablony).
2. Ustawienia → Templates → **Template folder location**: `szablony`.
3. W dowolnej notatce: Ctrl/Cmd+P → „Insert template" → wybierz szablon.
Opcjonalnie: włącz **Daily notes** (folder: `kronika/`, szablon: `szablony/kronika_dnia`).
Zapis: obsidian-git commituje przy Twoim ruchu; maski podejmują wpisy z pulla przy wstaniu.
